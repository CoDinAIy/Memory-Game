# Cat GIF Memory Game
This project is a fun and challenging Memory Game featuring adorable cat GIFs! The goal is to test your memory skills by remembering all 12 unique cat GIFs without clicking on any of them more than once. Can you win by keeping track of them all?

## 🌟 Features
**Adorable Cat GIFs:** Play with a collection of 12 fun and random cat GIFs.

**Memory Challenge:** Click each GIF only once. If you repeat, the game resets.

**Dynamic Gameplay:** The GIFs shuffle after each click, keeping you on your toes.

**Win Condition:** Successfully click all 12 unique GIFs without any repeats.
## 🚀 Play the Game
**Try it out here: [Cat GIF Memory Game](https://codinaiysmemorygame.netlify.app/)**

**JavaScript:** Handles the logic for shuffling GIFs and tracking clicks.
